# 라벨스캔

의약품 포장의 **제품명·성분명**을 카메라로 비추거나 사진·직접 입력으로 넣으면, 한국 마약류관리법상 **마약·향정신성의약품·대마·임시마약류·원료물질** 해당 여부를 사전과 대조해 보여 주는 오프라인 웹앱입니다.

- 접속 주소: https://lhk4309.github.io/labelscan/
- 처음 한 번 접속 후 **홈 화면에 추가**하면 인터넷 없이 사용할 수 있습니다.
- 사전에서 찾지 못하면 '사전 미등재'로 표시합니다(비해당 판정 아님).
- 공개자료 기반 참고용 도구이며, 최종 판단은 법령·공고 원문과 성분분석 결과에 따릅니다.

## 사전 출처(요약)
국내: 마약류관리법 시행령 별표1~8, 식약처 임시마약류 지정 공고 제2026-516호  
해외 제품: 미국 FDA NDC, 캐나다 DPD, EMA Article 57, 프랑스 BDPM, 영국 NHSBSA dm+d, 일본 후생노동성·PMDA, 중국 마약·정신약품 목록, 대만 TFDA, 인도, 베트남 DAV, 말레이시아 NPRA, 인도네시아 KFA, 필리핀 FDA, 미얀마 FDA, 스리랑카 NMRA, 홍콩 衞生署

## 구성
- `index.html`, `app.js`, `match.js` — 화면·판정 로직
- `data/dict.json` — 판정 사전(성분 658종, 검색어 약 1.4만 개)
- `vendor/` — 글자 인식 엔진 Tesseract.js(Apache-2.0)와 언어 데이터
- `sw.js` — 오프라인 저장(서비스 워커). 업데이트 시 `VER` 값을 바꿉니다.
